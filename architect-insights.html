Per-architect interaction data

This view is limited to the verified membership snapshot of Azure Data Plane API Reviewers. Automation selection, GitHub review approval, and valid approval are separate events. A valid approval belongs to the person who applied data-plane-review-signoff.

Automation routing selection: an individual review request created by azure-sdk-automation within 24 hours of the review entering the queue. It measures routing, not completed review work. Team, manual, and later requests are shown as context but are not counted as automation routing selections.
GitHub review approvals: unique pull requests where the handle submitted an APPROVED review. Repeated approvals by the same person on one PR count once.
Valid approval: a human application of data-plane-review-signoff. An application removed by automation within two minutes is excluded.
Median request-to-valid-approval: elapsed time from the review entering the queue to a valid approval label.

What can be learned

Workload distribution

Assignments and open work show whether review demand is concentrated and where balancing or additional coverage may help.

Waiting patterns

Request-to-signoff timing can identify review paths worth examining, but it includes service-team responses, PR readiness, and review complexity.

Automation opportunities

Repeatedly slow paths can be inspected for missing context, manual coordination, or routine checks that automation could prepare earlier.

Evidence limits

GitHub events measure workflow elapsed time, not cognitive effort. This page links the PRs that support displayed counts, but it does not publish raw event payloads, comments, tokens, or private telemetry.

Public architect evidence extension. Handles are plain text and do not create GitHub mentions.
