Data and refresh

Collection

A scheduled collector reads public GitHub Actions runs and PR lifecycle events. Unchanged PR timelines are cached to reduce API load.

Calculation

The generator rebuilds cohort, latency, throughput, integrity, and backlog metrics. Open PRs count as backlog; closed and merged PRs do not.

Validation and privacy

Automated tests validate pairing, percentiles, cohort boundaries, and backlog state. Raw event records, pull-request evidence, and private telemetry are excluded from public pages.

Artifacts

The scheduled refresh publishes this aggregate report and a separate architect interaction extension. Detailed evidence and the Azure Workbook remain private.
